# Префиксы, суффиксы, мета

[English](../Prefixes-and-meta) · **Русский**

Префикс, суффикс и произвольная мета хранятся как ноды.

| команда | нода |
| --- | --- |
| `meta addprefix 100 "&c[Admin] "` | `prefix.100.&c[Admin] ` |
| `meta addsuffix 10 "&7"` | `suffix.10.&7` |
| `meta set clan wolves` | `meta.clan.wolves` |

Побеждает префикс/суффикс с большим приоритетом. `/vcp user Steve meta info` показывает, что реально висит. `/vcp user Steve info` показывает уже разрешённые, если есть контекст.

vcPerms **не** переписывает чат, пока `apply-chat-meta: true` не включён. Если чат уже форматирует другой плагин — оставьте выкл и читайте префикс через [IPC](API).
